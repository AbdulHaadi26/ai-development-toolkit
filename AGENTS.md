# Repository instructions

- Read `README.md` and `CONTRIBUTING.md` before making changes.
- The reusable, product-neutral source is in `workflow-kit/`. Keep adopting-project code, data, design decisions, backlog, and change history in those projects.
- Make changes on a feature or fix branch and open a pull request against `main`; never push directly to `main`.
- When changing portable behavior or templates, review `workflow-kit/ADOPTION.md` and update `workflow-kit/VERSION` using its versioning rules.
- Run the formatting and link/path checks listed in `CONTRIBUTING.md`; report only checks actually run.
